# claude-template

Starter template for webapps and websites: Vite + React 19 + TypeScript +
react-router + Tailwind 4 + shadcn/ui (radix primitives) + visx charts +
motion + number-flow, wired for Claude Code with project skills.

## Commands

- `pnpm dev` - dev server (Vite, http://localhost:5173)
- `pnpm build` - type-check (`tsc -b`) then production build
- `pnpm lint` - oxlint over src/
- `pnpm format` - prettier over src/
- `npx shadcn@latest add <component>` - add shadcn components (official registry)

## Conventions

- Follow the `design-system` project skill for ALL UI work: package routing
  (motion for animation, visx for charts, lucide for icons), CSS-variable
  theming, dark mode via `.dark` class. No new UI dependencies without asking.
- Follow the `dashboard-insights` project skill BEFORE building or changing
  any dashboard surface: interview, decision test, metric hierarchy, sign-off.
- `src/components/ui/` is generated by the shadcn CLI - never hand-edit.
- Path alias: `@/` maps to `src/`.
- Routes in `src/App.tsx`, pages in `src/pages/`, shared components in
  `src/components/`.
- `src/pages/dashboard-demo.tsx` and `src/components/demo/` are the living
  reference implementation of the stack. Keep them building; they double as
  the smoke test.

## Theming

Tokens live in `src/index.css` (shadcn vega preset, neutral). To rebrand:
edit the `:root` and `.dark` variable blocks only - components reference
tokens, never raw colors, so a token swap restyles everything including
charts.
